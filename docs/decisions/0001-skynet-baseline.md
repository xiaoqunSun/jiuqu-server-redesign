# ADR 0001：Skynet 上游基线

- 状态：已采纳
- 日期：2026-10-21

## 决策

使用官方 `cloudwu/skynet` 的 `v1.8.0` 发布版作为新项目基线，通过 Git submodule 固定源码。该标签解析到：

- 仓库：<https://github.com/cloudwu/skynet.git>
- 发布标签：`v1.8.0`
- 提交：`ba64be6f9fa044933c77de1317f466afbade8eaa`

项目不跟随上游分支自动更新。升级时需更新 submodule 指针并记录变更原因、Lua/C ABI 和依赖兼容性检查结果。

## 原因

选择正式发布标签，能让新服务端从一个有明确版本边界的上游快照开始，降低跟随开发分支变化带来的不确定性。精确提交保证源码可复现。上游发布页显示 `v1.8.0` 是 2024 年发布版，当前 master 在其后已有 58 个提交；本项目优先采用发布版的可预测性，后续根据实际需求评估升级。

## 验证要求

在选择生产运行时前，验证目标平台构建，并检查 protobuf、JSON、zlib、TLS/HTTP、数据库客户端等本地模块与其 Lua ABI 的兼容性。若关键依赖无法支持此版本，应通过新 ADR 评估升级到更新发布版或维护必要的兼容补丁。
